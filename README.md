# Basic Coding Sessions with PROA Friends

Repositório com projetos desenvolvidos durante sessões de programação com amigos do PROA.

Cada pasta contém um projeto desenvolvido durante uma sessão, junto com os arquivos e materiais relacionados.

## Projetos

### 01 — Landing Page 24H STUDIO

**Descrição:**
Landing page de apresentação de um template de portfólio no Figma, com botões e uma barra de logos.

**O que fizemos:**
- Estrutura inicial de uma landing page com header e seção hero
- Estilização com CSS (Flexbox, hover, espaçamentos com rem)
- Barra de logos com imagens
- Aprendemos sobre tags HTML, seletores CSS e unidades de medida (rem)

**Tecnologias:**
- HTML
- CSS
